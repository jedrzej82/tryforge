## 🚀 Jak Używać

### 1. Quick Start (5 minut)

```bash
git clone https://github.com/jedrzej82/tryforge.git
cd tryforge
npm install
npm start
# Otwórz: http://localhost:3000
```

### 2. Interactive CLI Mode (Domyślny)

```bash
npm link
tryforge create

# System rozmawia:
> Co chcesz stworzyć?
"sklep internetowy"

> Świetnie! Kilka pytań:
> 1. Co sprzedajesz?
> 2. Ile produktów?
> 3. Płatności?

# Odpowiadasz i system generuje!
```

### 3. Guided Mode (Dla Początkujących)

```bash
tryforge create --guided

# Step-by-step wizard:
> Krok 1/5: Co chcesz stworzyć?
> [1] Web app
> [2] Mobile app
> [3] Desktop app
> [4] Gra
> [5] Coś innego
```

### 4. Expert Mode (Dla Zaawansowanych)

```bash
tryforge create my-app \
  --template marketplace \
  --backend fastapi \
  --database postgres \
  --features auth,payments,admin \
  --no-interactive
```

### 5. Visual Tools

```bash
# Visual Editor
tryforge editor ./my-project

# Workflow Builder
tryforge workflow

# Full Web App
npm start
```
