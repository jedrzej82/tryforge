## 🤝 Contributing Examples

Created an app with TryForge? Share it!

**How to add your example:**

1. Create a folder: `examples/your-app-name/`
2. Include:
   - README.md - Description and screenshots
   - TIME.md - How long it took
   - FEATURES.md - List of features created
   - (Optional) Screenshots
   - (Optional) Link to live demo
   - (Optional) Link to source code

3. Submit a Pull Request!
