# TryForge Example: Blog Platform

This example demonstrates how to use TryForge to create a full-featured blog platform in minutes.

## Created With

```bash
tryforge create my-blog --type blog
```

## Features

- ✅ User authentication
- ✅ Post creation and editing
- ✅ Comments system
- ✅ Categories and tags
- ✅ Search functionality
- ✅ Responsive design
- ✅ Dark mode
- ✅ AI-generated graphics

## Tech Stack

- **Frontend**: React + Vite
- **Backend**: Express + Node.js
- **Database**: PostgreSQL
- **Graphics**: Pollinations AI
- **Components**: GitHub Spark
