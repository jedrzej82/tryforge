# Contributing to TryForge

Thank you for your interest in contributing to TryForge!

## 🎯 What is TryForge?

TryForge is a Triple AI Application Framework that enables creating production-ready web applications in minutes using Claude Code CLI.

## 📝 Documentation Contributions

The most valuable contributions right now are:

### 1. Documentation Improvements
- Fixing typos and grammar
- Adding clarifications
- Translating to other languages
- Adding more examples

### 2. Example Projects
- Create apps using TryForge
- Document the process
- Share before/after metrics
- Add to examples/ directory

### 3. Workflow Documentation
- Real-world use cases
- Tips and tricks
- Best practices
- Common pitfalls

## 🚀 How to Contribute

### Documentation

1. Fork this repository
2. Create a branch: `git checkout -b docs/your-improvement`
3. Make your changes
4. Commit: `git commit -m "docs: describe your changes"`
5. Push: `git push origin docs/your-improvement`
6. Create a Pull Request

### Example Projects

1. Use TryForge to create an app
2. Document the process
3. Share your experience
4. Submit as an example

## 📋 Documentation Standards

### File Naming
- Use UPPERCASE for main docs (README.md, ARCHITECTURE.md)
- Use lowercase for examples (example-blog.md)
- Use kebab-case for multi-word files

### Writing Style
- Clear and concise
- Use code examples
- Include time estimates
- Add screenshots/diagrams when helpful

### Language
- Primary language: English
- Polish translations welcome in /docs/pl/
- Other languages in /docs/{lang}/
