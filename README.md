# 🔥 TryForge

**Triple AI Application Framework**

*Try. Forge. Deploy.*

---

## What is TryForge?

TryForge is a revolutionary framework that uses **Triple AI** (Claude + GitHub Spark + Pollinations AI) to automatically create production-ready web applications in minutes, not hours.

**From idea to working app in 5-10 minutes.**

---

## 🚀 Quick Overview

```
You:     "create: E-commerce store for handmade jewelry"

TryForge:
→ Pollinations AI: Generates custom graphics, logos, product images
→ GitHub Spark: Creates React components and modern UI
→ Claude: Builds backend API and database
→ Result: Full working e-commerce app in 7 minutes
```

---

## ✨ Key Features

- **🤖 Triple AI** - Three AI services working in parallel
- **⚡ Ultra Fast** - 5-10 minutes from idea to app

## 🤖 Triple AI Explained

### How It Works:

**1. Claude (Orchestrator + Backend)**
- Understands your requirements
- Plans architecture
- Creates descriptions for other AIs
- Builds backend and database
- Integrates everything

**2. Pollinations AI (Graphics)**
- Generates custom graphics based on Claude's descriptions
- Creates logos, hero images, icons, illustrations
- Unique visuals for every project

**3. GitHub Spark (Frontend)**
- Creates UI components based on Claude's descriptions
- Modern React/Vue components
- Responsive design
- Dark mode support

**All three work in parallel → 3x faster!**

## 🚀 Quick Start

### 1. Install

See [SETUP.md](SETUP.md) for complete installation instructions.

**Requirements:**
- Ubuntu VirtualBox VM
- Node.js 18+
- PostgreSQL 14+
- Claude Code CLI

**Time:** 30-45 minutes (one-time)

### 2. Create Your First App

```bash
cd ~/your-project
claude

# In Claude Code CLI:
create: Simple blog platform

# Wait ~5 minutes
# App ready!
```

### 3. Access Your App

```
Frontend: http://localhost:5173
Backend:  http://localhost:3000
```
